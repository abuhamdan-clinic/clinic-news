# clinic-news
Daily nutrition news for clinic app — أخبار تغذية يومية لتطبيق «العيادة الذكية».

## الملف الرئيسي: `news.json`
يُحدَّث يوميًا الساعة 7:00 صباحًا بتوقيت عمّان بواسطة مهمة مجدولة.
التطبيق يقرأه فقط من الرابط:
`https://raw.githubusercontent.com/abuhamdan-clinic/clinic-news/main/news.json`

### الحقول
| الحقل | المعنى |
|---|---|
| `updated` | وقت آخر تحديث (UTC) |
| `sources` | الجهات المعتمدة: الاسم، نص الشارة، النطاق، اللون، الموقع |
| `items` | الأخبار، الأحدث أولًا |

### حقول الخبر
| الحقل | مثال |
|---|---|
| `id` | `2026-10-27-who-sugar` (ثابت ولا يتكرر) |
| `date` | تاريخ نشر الخبر في المصدر `2026-10-27` |
| `title` | جملة عربية قصيرة (أقل من 20 كلمة) بصياغتنا |
| `category` | `news` أخبار / `recommendation` توصيات / `regulation` قوانين وتحديثات |
| `scope` | `global` عالمي / `local` محلي (الأردن) |
| `source` | مفتاح الجهة من `sources` |
| `url` | رابط صفحة الخبر نفسه (وليس الصفحة الرئيسية للجهة) |
| `image` | رابط صورة الخبر كما نشرها المصدر (og:image) أو `""` إن لم توجد؛ لا تُنسخ الصورة ولا تُرفع هنا |
| `added` | تاريخ إضافته للملف |

## القواعد
- مصادر رسمية فقط، ولكل خبر رابط أصلي.
- لا نسخ حرفي؛ صياغة مختصرة مع ذكر المصدر.
- لا شعارات رسمية؛ التطبيق يرسم «شارة مصدر» من `badge` و`color`.
- صورة الخبر تُعرض من رابطها الأصلي مع ذكر المصدر، وإن لم توجد يرسم التطبيق صورة بديلة حسب القسم.
- يُحتفظ بأخبار آخر 30 يومًا (حد أقصى 150 خبرًا) حتى يتمكن التطبيق من مراجعتها.
- الموافقة على الأخبار تتم داخل التطبيق (الموافقة أولًا)؛ هذا الملف لا يحتوي بيانات مرضى.

> المعلومات للتوعية ولا تغني عن استشارة المختص.
